# Documentation Guide

Welcome to the documentation for this project! If you are new to the repository, we recommend reading the files in this directory in the following order to get a comprehensive understanding of the project's background, approach, and outcomes:

1. **[dataset_overview.md](dataset_overview.md)**  
   Start here to understand the data used in this project. This document covers the source, schema, distribution, and fairness considerations of the dataset.

2. **[methodology.md](methodology.md)**  
   Once you understand the data, read this file to learn about the data transformations, machine learning pipelines, and the bias mitigation strategies (such as those using Fairlearn) implemented in the code.

3. **[results.md](results.md)**  
   After reviewing the methodology, this document will walk you through the outcomes of our experiments, including model performance metrics and fairness audits.

4. **[limitations.md](limitations.md)**  
   No approach is perfect. This file highlights the caveats, assumptions, and potential shortcomings of the current methodology and results.

5. **[reproduction_guide.md](reproduction_guide.md)**  
   Finally, when you're ready to run the code yourself, this guide provides the step-by-step instructions to set up the environment and reproduce the pipeline locally.

> **Note**: The `slides/` directory contains presentation materials summarizing the project's key findings for a broader audience.
